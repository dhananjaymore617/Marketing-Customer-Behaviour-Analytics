# Data

The project uses customer journey, customer review, customer, engagement, geography, and product datasets.

## Source files

- `customer_journey.csv`
- `customer_reviews.csv`
- `customers.csv`
- `engagement_data.csv`
- `geography.csv`
- `products.csv`
- `fact_customer_reviews_with_sentiment.csv`

The raw source files will be added to this directory as part of the repository data package. The sentiment-enriched review dataset is the prepared review dataset used for customer feedback analysis.
