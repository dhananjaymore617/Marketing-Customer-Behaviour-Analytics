# Power BI

This folder contains the Power BI implementation and documentation for the marketing and customer behaviour analytics solution.

## Dashboard pages

- Overview
- Conversion Details
- Social Media Details
- Customer Review Details

## Model

The Power BI model uses dimension and fact tables, including:

- `dim_customers`
- `dim_products`
- `dim_geography`
- `Calendar`
- `fact_customer_journey`
- `fact_customer_reviews`
- `fact_customer_reviews_with_sentiment`
- `fact_engagement_data`

The final PBIX file, DAX measures, model screenshot, and dashboard screenshots will be added here.
