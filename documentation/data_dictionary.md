# Data Dictionary

## Customer Journey

| Column | Purpose |
|---|---|
| JourneyID | Identifier for a customer journey event |
| CustomerID | Customer identifier |
| ProductID | Product identifier |
| VisitDate | Date of the journey event |
| Stage | Customer journey stage |
| Action | Customer action at the stage |
| Duration | Duration associated with the journey event |

## Customer Reviews

| Column | Purpose |
|---|---|
| ReviewID | Review identifier |
| CustomerID | Customer identifier |
| ProductID | Product identifier |
| ReviewDate | Review date |
| Rating | Customer rating |
| ReviewText | Customer review text |

## Engagement Data

The engagement dataset contains engagement identifiers, content/campaign/product identifiers, content type, views, clicks, likes, and engagement date.

## Customers

Customer attributes include customer identifier, name, email, gender, age, and geography identifier.

## Geography

Geography attributes include geography identifier, country, and city.

## Products

Product attributes include product identifier, product name, category, price, and price category.

## Sentiment-enriched reviews

The enriched review dataset extends customer review data with sentiment-related fields used in the Power BI customer feedback analysis.
